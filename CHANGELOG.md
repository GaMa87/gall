## Unreleased

## 0.3.1 — 2026-11-27

- Fixed: removed the misleading open-left/open-right pane picker icons and "Open in new tab / other browser" menu items from Trash in the sidebar (Trash always opens in its own window); on Linux, unlocking an encrypted volume now checks for a saved desktop-keyring passphrase in both KDE KWallet (`SolidLuks` via `kwallet-query`, matching Dolphin/Solid) and GNOME Keyring (`gvfs-luks-uuid` via `secret-tool`) before prompting, offers an optional "Remember passphrase in system keyring" checkbox to save verified passphrases into the active desktop's keyring, waits briefly for desktop automount before issuing a second `udisksctl mount` (avoiding redundant polkit prompts), stops looping the passphrase dialog when polkit authorization is cancelled, and explains the separate polkit authorization prompt on internal partitions.
- Changed: made Quick Open EDR-friendly by default — Unix default indexed root is now `$HOME` instead of `/` (while typing `/path`, `~/path`, or `C:\path` in Quick Open performs live single-directory completion with `Tab` directory completion), default `index_refresh_minutes` is now `0` (rebuild on demand when Quick Open opens; migrated once from the previous default `15`), and the background walker is capped at 4 threads with Linux `IOPRIO_CLASS_IDLE` I/O priority.
- Fixed: eliminated idle and high-frequency background disk writes, subprocess spawns, and unfocused polling — capped `gall.db-wal` via `wal_autocheckpoint = 512` and `journal_size_limit = 524288` (shrinking oversized legacy WALs on open and truncating on clean exit/update restart), wrapped history, destination, and tag-rename updates in single transactions, stopped logging routine background polls (`system_stats`, `list_drives`, `other_volumes`, `gvfs_network_mounts`, `list_cloud_folders`, `selection_publish`, `grep_context`) to `diagnostics.json` while raising its periodic flush interval from 2 s to 30 s, moved ephemeral `selection.json` into the runtime directory (`$XDG_RUNTIME_DIR/gall` in RAM on Linux, fixing the duplicate `gall/gall` subfolder) with duplicate-write suppression, coalesced `session.json` saves over a 3 s window and skipped unchanged `JsonStore::save` rewrites, cached Linux `lsblk` and `gio mount -l` snapshots against kernel/GVFS fingerprints so idle polling spawns zero subprocesses, paused sidebar drive, cloud, network, and system-monitor polling while unfocused with in-flight guards, merged Linux `/sys/class/drm` GPU reads into one pass, fixed an infinite inotify `Access` self-retrigger loop in `omarchy-watch`, and respected `index_refresh_minutes = 0` at startup.
