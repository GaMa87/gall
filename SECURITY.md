# Security policy

Gall manipulates files on your computer, so security reports are taken seriously.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's
[private vulnerability reporting](https://github.com/GaMa87/gall/security/advisories/new).
You will get an acknowledgement within 7 days.

Useful details: affected version, platform, steps to reproduce, and impact
(e.g. path traversal, data loss, code execution via crafted file names or previews).

## Supported versions

Only the latest release receives fixes while the project is pre-1.0.
