05 / Install

Up and running in seconds.

Prebuilt packages for Linux, Windows, and macOS — with signed background updates and a zero-install portable ZIP for Windows.

Install via Fedora COPR

Tracks releases automatically and registers Gall as a system file manager (so Meta+E can launch Gall on Plasma).

sudo dnf copr enable gama87/gall && sudo dnf install gall

Also available as standalone .rpm, .deb, and AppImage packages on GitHub Releases.

Any Linux distribution

Download the AppImage, .deb (Debian, Ubuntu, Mint), or .rpm (Fedora, openSUSE) from GitHub Releases.

chmod +x Gall_*.AppImage && ./Gall_*.AppImage

Debian/Ubuntu: sudo apt install ./Gall_*.deb · Fedora/openSUSE: sudo dnf install ./Gall-*.rpm. Optional xdg-desktop-portal-gall FileChooser backend included in packaging.

Windows 10 / 11 (Installer, MSI, or Portable ZIP)

Choose the setup .exe / .msi installer, or unzip the portable build anywhere and run gall.exe.

Gall-<version>-windows-x64-portable.zip Releases →

USB-ready: create an empty file named portable next to gall.exe to keep all settings, cache and logs in ./UserData beside it. WSL distributions appear directly in the Drives sidebar.

macOS (Apple silicon & Intel)

Download Gall_<version>_aarch64.dmg (Apple silicon) or _x64.dmg (Intel), open it, and drag Gall to Applications.

open -a Gall ~/Projects

Note: macOS builds are not notarised yet — if macOS blocks first launch, allow it in System Settings › Privacy & Security › Open Anyway.

Get the latest release

Signed updates check in the background and restart straight into new versions. Full source, issue tracker, and documentation live on GitHub.
